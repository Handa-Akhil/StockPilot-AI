# StockPilot AI

StockPilot AI is an AI-powered investment platform that helps retail investors understand stock markets by combining live market data, technical indicators, company fundamentals, news, sentiment analysis, and AI-generated explanations into one intelligent platform.

## Monorepo layout

| Path | Purpose |
|------|---------|
| `backend/` | API and core application services |
| `frontend/` | Web client application |
| `ai-service/` | AI / ML inference and analysis services |
| `database/` | Schema, migrations, and seed assets |
| `docker/` | Container-related configuration |
| `docs/` | Product, architecture, and delivery documentation |
| `scripts/` | Automation and utility scripts |
| `infrastructure/` | Cloud / IaC definitions |
| `tests/` | Cross-cutting and integration test assets |
| `.github/workflows/` | CI/CD workflow definitions |
