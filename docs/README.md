# Documentation

Product, architecture, and delivery documentation for StockPilot AI.

## Structure

| Folder | Contents |
|--------|----------|
| `01-Research` | Market and technical research |
| `02-PRD` | Product requirements |
| `03-User-Personas` | Target user personas |
| `04-User-Stories` | User stories and acceptance criteria |
| `05-Wireframes` | UX wireframes and flows |
| `06-HLD` | High-level design |
| `07-LLD` | Low-level design |
| `08-Database` | Data model documentation |
| `09-API` | API contracts and guides |
| `10-AI` | AI system design and prompts |
| `11-Sprints` | Sprint plans and notes |
| `12-Deployment` | Deployment runbooks |
| `Assets` | Shared documentation assets (`images/`, `diagrams/`, `logos/`, `icons/`) |
